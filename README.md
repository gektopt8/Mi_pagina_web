# Guía de Rocket League — Proyecto Web Cuatrimestral

## 📝 Descripción
Este proyecto es una guía web interactiva sobre el videojuego **Rocket League**. Está diseñada como un recurso integral para jugadores de todos los niveles, centralizando información sobre controles, configuraciones óptimas, análisis de vehículos (*hitboxes*), tablas de rangos y videotutoriales de mecánicas.

---

## 📂 Estructura y Contenido
El sitio web se organiza en las siguientes secciones accesibles desde el menú de navegación:
* **Inicio:** Introducción al juego, su historia y su transición al modelo *Free to Play*.
* **Controles:** Mapeo de teclas para teclado/mouse y recomendaciones de optimización.
* **Configuración:** Ajustes profesionales de cámara y parámetros gráficos para maximizar FPS.
* **Autos:** Tablas comparativas de los coches más usados en *Competitivo* y *Freestyle* según su *hitbox*.
* **Mecánicas:** Sección dividida por niveles (*Principiante*, *Intermedio* y *Avanzado*) con explicaciones teóricas y videotutoriales de YouTube integrados.
* **Rangos:** Escala estimada de rangos en base a las horas de juego invertidas.
* **Contacto:** Formulario funcional de comunicación en el pie de página.

---

## 🛠️ Tecnologías Aplicadas
* **HTML5:** Estructuración semántica del sitio utilizando etiquetas de bloque (`<nav>`, `<main>`, `<article>`, `<section>`), tablas y formularios.
* **CSS3:** Diseño visual personalizado con fondos oscuros temáticos y tipografías externas de Google Fonts (*Bebas Neue* y *Chakra Petch*).
* **Navegación Avanzada:** Implementación de un menú fijo (`position: fixed`) con submenú desplegable nativo mediante transiciones y estados `:hover`.
* **Optimización de UX:** Uso de `scroll-padding-top` y `scroll-behavior: smooth` para evitar superposiciones del menú fijo durante la navegación por enlaces de ancla.

---

## 💻 Ejecución
Para visualizar el proyecto de forma local, abra el archivo `index.html` en cualquier navegador web moderno. 
*(Nota: Se requiere conexión a internet para cargar las tipografías y los videos).*
